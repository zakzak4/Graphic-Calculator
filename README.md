# ZakCalculator

A clean and functional desktop calculator application built using C# and Windows Forms. This project features a custom graphical user interface, utilizing specialized UI components for a polished look and feel.

## Technologies Used
* C# (.NET Framework)
* Windows Forms (WinForms)
* Visual Studio

## Features
* **Custom UI Components:** Uses specialized button classes (`Button_WOC`) for a non-standard, modern design.
* **Basic Arithmetic:** Supports standard mathematical operations (addition, subtraction, multiplication, and division).
* **Responsive Interface:** Designed to handle user input via both mouse clicks and keyboard events.

## Project Structure
* `Form1.cs` - The main calculator interface and logic.
* `Button_WOC.cs` - Custom control class used to create the stylized buttons.
* `Program.cs` - The standard entry point for the application.
* `App.config` - Configuration settings for the environment.

## Setup Instructions
1. Open `ZakCalculator.sln` in Visual Studio.
2. Build the solution to ensure all custom components are compiled.
3. Run the application to start using the calculator.
